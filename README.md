# NFL Combine to NFL Performance Analysis

## Overview

This project investigates whether movement characteristics captured through NFL Combine tracking data can provide additional insights into players' future NFL performance.

The project is being conducted as an exploratory, research-oriented analysis using data from the NFL Big Data Bowl 2027 competition.

## Research Question

Do sensor-derived movement characteristics from NFL Combine drills provide additional information about future NFL performance beyond traditional Combine measurements?

## Objectives

- Understand and validate the datasets before analysis.
- Explore traditional Combine measurements and career-performance variables.
- Analyze player movement characteristics using tracking data.
- Develop meaningful movement-based features.
- Investigate relationships between Combine movement profiles and future NFL performance.
- Establish a data-driven foundation for subsequent statistical analysis and machine learning.

## Current Progress

- Dataset exploration and validation.
- Wide receiver subgroup investigation.
- Analysis of 40-yard dash performance.
- Exploration of speed, acceleration, trajectory, and movement-derived measurements.
- Event-level feature engineering.
- Ongoing investigation of data patterns and quality.

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, Scikit-learn.

## Project Status

🚧 Work in progress. The research question, analysis, and methodology are being refined as the investigation progresses.
